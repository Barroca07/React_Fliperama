# 🕹️ React Fliperama

Uma coleção interativa de mini-jogos clássicos construída inteiramente como uma Single Page Application (SPA). Este projeto serve como um laboratório prático para consolidar conceitos fundamentais de desenvolvimento front-end, lógica de programação e gerenciamento de estado complexo no ecossistema React.

## 🔗 Acesse o Projeto
👉 **[Jogue agora no GitHub Pages](https://barroca07.github.io/React_Fliperama/)**

## 🎮 Jogos Inclusos

* **Snake (Jogo da Cobrinha):** O clássico jogo de agilidade e reflexos. Ideal para praticar manipulação contínua de estado, detecção de colisões e controle de intervalos de tempo (game loops) dentro do React (`Snake.js`)[cite: 2].
* **Campo Minado (Minesweeper):** Jogo de raciocínio lógico e dedução[cite: 2]. Desenvolvido para treinar a manipulação de matrizes (arrays bidimensionais), algoritmos de recursão e múltiplos estados simultâneos (`Minesweeper.js`)[cite: 2].
* **Jogo da Velha (Tic Tac Toe):** O tradicional jogo de estratégia[cite: 2], focado em implementar lógica de vitória algorítmica, alternância de turnos e imutabilidade de estado (`TicTacToe.js`)[cite: 2].

## 🛠️ Tecnologias e Estrutura

O projeto foi construído utilizando as seguintes tecnologias e componentes:

* **React (JavaScript):** Responsável por toda a lógica de renderização, gerenciamento de ciclo de vida e componentização (`App.js`)[cite: 2].
* **HTML5:** Estrutura base da aplicação (`index.html`)[cite: 2].
* **CSS3:** Estilização personalizada de tabuleiros, menus, animações e responsividade (`style.css`)[cite: 2].
