# 🕹️ React Fliperama

Uma coleção interativa de mini-jogos clássicos construída inteiramente como uma Single Page Application (SPA). Este projeto serve como um laboratório prático para consolidar conceitos fundamentais de desenvolvimento front-end, lógica de programação e gerenciamento de estado complexo.

## 🔗 Acesse o Projeto
👉 **[Jogue agora no GitHub Pages](https://barroca07.github.io/React_Fliperama/)**

## 🎮 Jogos Inclusos

* **Campo Minado (Minesweeper):** O clássico jogo de raciocínio lógico e dedução. Desenvolvido para treinar a manipulação de matrizes (arrays bidimensionais), algoritmos de varredura e múltiplos estados simultâneos no React.
* **Jogo da Velha (Tic Tac Toe):** O tradicional jogo de estratégia, focado em implementar lógica de vitória, alternância de turnos e imutabilidade de estado.

## 🛠️ Tecnologias e Estrutura

O projeto foi construído utilizando as seguintes tecnologias:

* **React (JavaScript):** Responsável por toda a lógica de renderização, gerenciamento de ciclo de vida e componentização (`App.js`, `TicTacToe.js`, `Minesweeper.js`).
* **HTML5:** Estrutura base da aplicação (`index.html`)[cite: 1].
* **CSS3:** Estilização personalizada de tabuleiros, animações e responsividade (`style.css`)[cite: 1].
